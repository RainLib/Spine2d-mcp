# Mesh 与权重操作

## 检查

从实际 skin／slot／attachment 清单确定目标。读取 UV、三角形、加权顶点和骨骼索引，检查按边连通、未使用顶点、重复／退化三角形、非流形边／顶点扇和绕序。只在一个点相接的两个三角扇不算连续表面。

总附件数包括不同皮肤和互斥状态；多个附件不等于主体被拆碎。连续性是拓扑性质，也不能证明原画覆盖完整、动画不折叠或遮挡正确。网格预算取自任务的显示尺寸与性能目标，不继承某个游戏的数值。

## 修改现有绑定

`mesh_weights_get` 每次最多 256 个顶点，报告 UV、骨骼名、局部绑定坐标和权重。

```json
[{"vertex": 12, "weights": {"head": 1}}]
```

传给 `mesh_weights_set` 的更新**替换**该顶点的影响集合：省略的影响被移除，零权重被移除，正权重归一化。只能选择该顶点已有绑定的骨骼；添加新绑定需显式计算局部坐标。保留 bind x/y 不保证当前姿态完全不变。

本包会把被编辑附件的**全部顶点影响列表**按骨骼索引排序；未选顶点的权重值与绑定坐标保持不变。原生编辑器曾暴露“只排序修改行、其余行混用顺序”的导入失败，因此本地扩展也应保持整个附件的影响顺序一致。不可把有 Deform 依赖的数据也直接重排。

## 替换网格与重新绑定

`mesh_replace` 需要 `uvs`、`triangles`、`vertices`、`hull`，可选 `edges`。保留已有附件的纹理与其他元数据。hull 顶点排在前面；三角形用顶点索引；本工具的 nonessential edges 使用 `2 * vertex_index` 坐标偏移。省略 edges 会清除旧边元数据。

当前替换只接收一个连续表面、一个边界环；有洞或多片网格须使用明确支持它们的本地生成／验证路径，不能静默填洞或丢弃部件。工具不做几何自相交检测，也不从 PNG 自动提取轮廓。

加权 vertices 每行记录影响数及各影响的骨骼索引、骨骼局部 x/y、权重。用 `pack_vertices` 可从命名影响编码；新绑定坐标需通过实际骨骼世界变换反算。不要把图片像素、slot 或世界坐标直接写为骨骼局部坐标。格式依据 [Spine JSON attachments](https://esotericsoftware.com/spine-json-format#Attachments)。

当前 mesh 编辑仅支持 Spine 4.3.x；文档含 linked mesh、image sequence、Deform／FFD／attachments 动画时间线时明确拒绝，普通 slots 下的附件切换时间线仍可用。不要通过删掉这些时间线来让检查通过。若任务确需修改依赖网格，必须通过支持依赖重映射的实际编辑器／实现完成并验证；否则保留原始数据并报告缺口。

### 需要本地实现 Deform 迁移时

这不是内置功能，也不能仅传入一个 `ProjectAdapter` 回调就声称完成。先按目标版本的真实加载器解析依赖；概念参考 [Spine Deform timeline](https://esotericsoftware.com/spine-json-format#Deform-timeline)，通用文档中的路径与字段仍需与目标版本核对。

- 列举所有引用该网格的 skin、linked mesh、动画及时间线，保存完整输入与哈希。选中的顶点必须来自当前拓扑的明确区域，不能猜哪个顶点代表脸部。
- 按当前版本解码帧的稀疏 `offset`、省略项及零增量，区分未加权顶点的坐标对和加权网格每个影响记录对应的增量布局；不要按 UV 顶点数直接截断加权 Deform 数组。
- 建立旧顶点／骨骼影响到新记录的映射，再迁移全部受影响帧。影响排序、删除、新增及拓扑变化必须显式处理；不能一边删影响，一边保留旧数组偏移。需要保留变形效果时，还要核对权重和局部坐标变换带来的变化。
- 在合成小样上验证稀疏帧、零帧、重排、删影响和 linked 依赖，再用相同历史逐帧比较原生结果。未选顶点及无关动画应保持其原有效果，不能串位、丢帧或消失；目标顶点允许的变化由本次要求定义。

更换绑定可能使目标顶点无法继续精确复现旧的多骨骼混合运动。明确“绑定变硬”与“所有旧姿态完全相同”的取舍；做不到时保留源数据并报告具体限制。没有完成原生导入与动画回归，不能把迁移器或静态校验的成功当作动画已保持正常。

## 区域规则

`mesh_policy_validate` 的规则是调用方数据，可描述 `continuous`、`max_vertices`、`max_influences` 和显式顶点区域中的 `rigid_bone`、`allowed_bones`、`forbidden_ancestors`。

面部刚性检查、披风直接权重隔离和祖先隔离分别表达不同要求。手臂权重为零，但衣摆骨骼挂在手臂之下，衣摆仍会被带动；约束和 Deform 也可能产生额外影响。

顶点区域选择依赖当前拓扑版本。重新布网后重建选择集，并绑定当前 JSON 的哈希；不能将旧顶点号套在新网格上。权重平滑或减小影响数后重新验证受保护区域、边界和极限姿态。
