# Brand assets

The project icon is unchanged. Only the banner was revised for the Spine2d-mcp repository name and compatibility presentation.

- `icon.png`: original AI-assisted skeletal-S project artwork, 1254 × 1254 RGBA; not an official vendor logo.
- `banner.png`: 2172 × 724 rendered composition. Preserves the original project icon at left; shows the official Spine mark separately and Codex / Claude Code as plain text.
- `banner.svg`: editable self-contained composition, with the original official Spine SVG bytes embedded as a base64 image, preserving aspect ratio. No official logo geometry, colors or proportions were edited.
- `spine_logo_dark.svg`: unchanged [official source](https://esotericsoftware.com/files/branding/spine_logo_dark.svg), provided by Esoteric Software under its [branding guidance](https://esotericsoftware.com/branding).
